Este pacote foi preparado para importação direta no StackBlitz.

Passos:
1. Crie um projeto novo no StackBlitz.
2. Importe este ZIP.
3. Aguarde a instalação automática.
4. Se necessário, rode manualmente:
   npm install
   npm run dev

Observações:
- O package-lock.json foi removido de propósito para o próprio StackBlitz gerar um lockfile compatível com o ambiente dele.
- O package.json está na raiz do projeto.
